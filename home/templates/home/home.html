Account

Four routes, one continuous flow

01

/signup

Creates a Django User with create_user(), so passwords are hashed automatically before the account exists

02

/signin

authenticate() checks the credentials, then login() attaches a session to the browser

03

/profile

A login_required view that reads and updates a one-to-one Profile model on the same page

04

/logout

logout() clears the session and sends the user back to a public homepage

Built to be reused

The account logic lives in its own Django apps with their own urls.py, views.py, and models.py. Because the templates extend one shared base and the views don't depend on anything specific to this portfolio, the whole package can be copied into a different Django project with only the static assets and branding swapped out

  • »Drop-in login and profile_detail apps
  • »One Profile model extends Django's built-in User
  • »Shared base template keeps every page on-brand
  • »No third-party auth service required
